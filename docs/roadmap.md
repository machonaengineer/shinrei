## 🚧 リスクと注意点（常時意識）

| リスク | 対策 |
|---|---|
| **AdSense 拒否**：「shocking content」分類 | 編集ポリシー厳守、断定表現ゼロ、適切な免責文 |
| **権利侵害クレーム** | 削除依頼フォームを目立たせる、24時間以内対応 |
| **トレスパス事故** | サイト全体で「訪問非推奨」を表示、警告ボックス |
| **SEO ペナルティ** | scraped content にならないよう description は独自テンプレ厳守 |
| **コミュニティ毒性** | 全投稿を承認制（既に実装済み）、通報・ブロック機能 |
| **Supabase / Vercel コスト** | 無料枠を超えたら CloudFlare R2 / Hetzner 等を検討 |
