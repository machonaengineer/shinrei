## 3. 独自ドメインの推奨（強く推奨）

AdSense 審査通過率は独自ドメインの方が大幅に高いです。Vercel デフォルトドメインでも通る例はありますが、ブランディング・信頼性・SEO 全てにとって独自ドメインは有効です。

オススメ：
- `shinrei-map.com`（英語複合語、空きがあるか要確認）
- `shinreimap.jp`（jp ドメイン、信頼性高）
- `shinrei.app`（短い、技術系の印象）

ドメイン取得：お名前.com / ムームードメイン / Cloudflare Registrar など。 Cloudflare Registrar は原価で安い。

設定手順:
1. ドメインを取得
2. Vercel → Project → Domains → Add → ドメイン名入力
3. DNS（A or CNAME レコード）を Vercel の指示通り設定
4. SSL 自動発行を待つ（通常数分）
5. `NEXT_PUBLIC_SITE_URL` を本ドメインに変更 → Redeploy

## 4. 申請のタイミング

最適: **コンテンツが充実してから1〜2週間後**（インデックス登録が進んでから）

審査基準で気にされる点:
- サイトの「年齢」（少なくとも数週間〜数ヶ月）
- インデックスされているページ数
- 月間 UU（数百〜数千あると好材料）
- スパムでない、独自性がある
- ナビゲーションが明確
- 連絡先がある

## 5. 申請後の流れ

1. AdSense ダッシュボードでサイトの「審査中」表示
2. **PIN コード**：収益が ¥1,000 相当（USD 約10）に達すると郵送される
3. PIN を AdSense に入力すると本人確認完了
4. 収益が ¥8,000 を超えた月末で翌月末払い

## 6. 拒否されたら

主な拒否理由と対応:

| 理由 | 対応 |
|---|---|
| Insufficient content | 記事を増やす、UU を増やす、月をまたいで再申請 |
| Site under construction | サイトの完成度を上げる、メイン機能を全て動作させる |
| Shocking content | 心霊・恐怖系の表現をさらに非断定化、記事を増やす |
| Navigation difficulties | ヘッダー・フッター・パンくずを確認、すべてのリンクが機能していること |
| Required policies missing | 利用規約・プライバシー・免責の明示的リンクを確認 |

再申請は拒否から **2週間以上空ける** のが推奨。
